# AlifeBalance: A-Life balance layer for STALKER Anomaly

AlifeBalance steers vanilla A-Life population toward what each level's own spawn configs declare. Respawn Pacing advances respawn cooldowns for depleted factions and delays overgrown ones, so fight regions recover fast while quiet maps stop drifting toward overcrowding. Spawn Size sends bigger squads for a faction losing across the Zone, and Squad Refill repairs the one-man remnant squads vanilla never repopulates, with a crowded-area check steering recovery toward the empty parts of a map. It rewrites nothing the engine owns, and every system toggles independently.
